# 見出し画像のプロンプト

生成先: Gemini（画像生成）
比率: 16:9

## 判断

- キーワード: **「3画面足りない」**（7文字。数と欠落を同時に言い切った）
- 被写体: 4枚の縦長パネル。左の1枚だけが行で埋まって光り、右の3枚は空・回転の弧・欠けた縁
- 色: 背景 `#0a0d1a`（ほぼ黒）／文字 `#ffffff`／アクセント `#a24a42`（赤茶）と `#2456e0`（藍）
  — **`demo/after.html` の `:root` から取り、明度を極端に振った**
- 美学: **強コントラストのプロダクト写真**（黒背景＋強い一灯）
- 傾き: 文字を 10度 傾ける

**月曜の `dashboard-3points` と同じサブ①なので、警告色（赤茶）を混ぜて差をつけた。**
あちらは藍1色。こちらは「3」だけ赤茶にして、欠けていることを色で示す。

## プロンプト

```
あなたは note の見出し画像を専門とするアートディレクターです。
以下の条件で16:9の画像を1枚作ってください。

## テキスト（これが主役・最優先）
「3画面足りない」を画像内に配置してください。

・画面の6割以上を文字が占める大きさにする
・極太のゴシック体（Black / Heavy 相当）。細い書体を使わない
・文字を10度、右上がりに傾ける。水平に置かない
・「3」の1文字だけ #a24a42（赤茶）にし、残りの「画面足りない」は #ffffff にする
・文字の背後から強い光が差し、文字の縁が白く光って見えるようにする
・背後のパネルに重なっても構わない。文字を避けて配置しない
・縮小表示でも読めることを最優先する

## 被写体（文字の背景として置く）
縦長の薄いパネルが4枚、横一列に並んでいる。

・左端の1枚: 横線が均等に7本引かれ、藍色に発光している。完成した状態
・2枚目: 面が完全に無地。中央に小さな四角い枠だけがある。光っていない
・3枚目: 中央に短い弧が1本だけ描かれている（回転の途中のような形）。光っていない
・4枚目: 面の一部が欠けていて、欠けた断面の縁だけが赤茶色に発光している
・どのパネルにも文字やアイコンを描き込まない
・左端の1枚だけが光り、右の3枚が暗い。この明暗差を強く出す
・文字の背後に置く。主役は文字である

## 色（3色まで。全部を強くする）
・背景: #0a0d1a（ほぼ黒）
・文字: #ffffff（「3」だけ #a24a42）
・アクセント: #2456e0（藍）を左端のパネルに、#a24a42（赤茶）を4枚目の断面に面で使う
・中間色・くすみ色・パステルを使わない
・藍と赤茶は最大彩度で発光させる

## 質感とライティング
・黒背景に強い一灯を当てたプロダクト写真
・強い一灯。左上からのリムライトでパネルの縁を光らせる
・影は硬く、濃く。パネルが床に落とす影の輪郭をはっきり出す
・高精細、ノイズなし、4K品質

## 避けるもの
・全面に敷くグラデーション
・複数の光源で影の方向がばらつくこと
・要素を3つ以上並べること（パネル4枚は1セットとして数える）
・爆発・炎・稲妻・札束・王冠
・画像内に「3画面足りない」以外の文字を書くこと
・脳のイラスト、光る回路基板、ロボットの手、青い網目状のネットワーク
・ローディングのスピナー、エラーの三角マーク、404 の数字
```
