# 見出し画像のプロンプト

生成先: Gemini（画像生成）
比率: 16:9

## 判断

- 被写体: 同じ形の歯車2つが1本の軸を奪い合って噛み合わず止まっている。その手前に、太い閂…（具体名詞。抽象概念を絵にしない）
- 色: デモが無いためサブカテゴリ②から選定。失敗を扱う回なので木曜デモの negative 色 #d64545 を継承
- 美学: 技術書の図版を極端に拡大したもの — 主題が排他と再試行という機構であり、構造を絵にできるため
- キーワード: 「2回走る事故」（6文字）

## プロンプト

```
あなたは note の見出し画像を専門とするアートディレクターです。
以下の条件で16:9の画像を1枚作ってください。

## テキスト（これが主役・最優先）

「2回走る事故」を画像内に配置してください。

・**画面の6割以上を文字が占める大きさ**にする
・極太のゴシック体（Black / Heavy 相当）。細い書体を使わない
・文字を **8度 傾ける**。水平に置かない
・文字の背後に強い光源を置き、縁が光って見えるようにする
・文字色は #ffffff。背景とのコントラストを最大にする
・被写体に重なっても構わない。**文字を避けて配置しない**
・縮小表示でも読めることを最優先する

## 被写体（文字の背景として置く）

同じ形の歯車2つが1本の軸を奪い合って噛み合わず止まっている。その手前に、太い閂（かんぬき）が1本だけ下りている

・文字の背後に置く。主役は文字である
・縁を光らせる（エッジライト）

## 色（3色まで。全部を強くする）

・背景: #0d0d10。明度を極端に振る（ほぼ黒）
・文字: #ffffff
・アクセント: #d64545。**1色だけ、面で使う**（線で使わない）
・中間色・くすみ色・パステルを使わない。縮小すると灰色になる

## 質感とライティング

・技術書の図版を極端に拡大したもの
・**強い一灯**。真横からのリムライト1つだけ
・影は硬く、濃く。柔らかい影は縮小すると消える
・高精細、ノイズなし、4K品質

## 避けるもの

・全面に敷くグラデーション
・複数の光源で影の方向がばらつくこと
・要素を3つ以上並べること
・爆発・炎・稲妻・札束・王冠
・画像内に煽り文句を書くこと
・爆発、炎、稲妻、エラーダイアログ風の絵、赤い警告三角、虫のアイコン
```

## 生成後の確認

- [ ] **サムネの大きさまで縮小しても、キーワードが読めるか**（最重要）
- [ ] 文字が画面の6割以上を占めているか
- [ ] 文字が傾いているか（水平に整列していないか）
- [ ] 中間色に逃げていないか。3色が全部強いか
- [ ] 記事のデモと色が揃っているか
- [ ] **画像内に煽り文句が入っていないか**（voice.md の ng は画像にも適用する）
