## 1. フック

読者が「自分のことだ」と感じる一文。**主語を読者にする。**

```
NG  AIを活用したコンテンツ販売の全体像を解説します
    → 主語が記事。読者は自分の話だと思わない

NG  あなたも月10万円を目指しませんか
    → 願望の提示であって、現状の名指しではない

OK  毎日「次は何を書こう」で手が止まる人は、ほぼ全員1つの罠にハマっています
    → 読者が今朝実際にやったことを言い当てている
```

## 2. 問題の可視化

**状態で書くと他人事、行動で書くと自分の話になる。**

```
NG  テーマが決まっていない人
NG  発信が続かない人
NG  自信がない人

OK  エディタを開いて、3日書けていない人
OK  下書きが4本たまったまま、どれも公開していない人
OK  公開ボタンの前で、タイトルを5回書き直した人
```

判定のコツ: その文が**動画に撮れるか**を考える。撮れなければ状態。

## 3. 再現性の4つの型

### 単純化

```
NG  リサーチをして、構成を作り、執筆し、校正し、画像を用意して、告知する
    → 6個ある。読んだ時点で「無理だ」と判断される

OK  今日やることは1つだけです。Routinesを1本作ってください
```

### 簡易化

```
NG  スキマ時間で無理なく続けられます
    → 数字がないので、読者の予定に置けない

OK  1日5分、3ステップ、30日で形になります
```

### 天井を下げる

これが一番効く。**大きい数字を出すほど読者から遠くなる。**

```
NG  この方法で私は月100万円を達成しました
    → すごいが、読者にとっては別世界の話

OK  100万は無理でも、5万円ならあなたでも作れます
    → 届く高さに置いたから財布が開く
```

profile.md に「累計100万」とあっても、そのまま書かない。
**読者が明日届く高さに置き直す。**

### 共感

```
NG  私も最初は苦労しました
    → 具体性がないので証拠にならない

OK  独学2年で稼いだのが累計1万1000円だった頃の話をします
    → 今の読者と同じ場所に立っていた証拠になる
```

## 4. 恐怖

### 1つに絞る

```
NG  このままでは稼げないままです。しかも時間も失います。
    さらに家族にも呆れられ、同期にも抜かれ、市場からも取り残されます
    → 5つある。記事が重くなり、集まる客層も荒れる

OK  1年後、同じことを1年ぶん長く悩んでいるだけになります
```

### 「もう手遅れ」にしない

```
NG  この分野はもう飽和しています。今から始めるには遅すぎます
    → 遅刻が確定した瞬間、人は走るのをやめる

OK  参入者は増えています。ただ、設計をやっている人はまだ少ない
    → まだ間に合う位置で止めている
```

### 地獄の種類で客層が決まる

| 地獄に置くもの | 集まる層 |
|---|---|
| お金がない | 支払い能力の低い層 |
| 時間を失う | 時間価値の高い層 |
| 後発に抜かれる | 既に動いている層 |

**ペルソナの支払い意欲が中〜高なら、「お金がない」を地獄に置かない。**

## 5. 買わない理由6つ

### C2 再現性がなさそう

```
NG  私は3ヶ月で100万を達成しました（自分の数字だけ）
    → 「この人がすごい」で止まる

OK  実績ゼロでPCも苦手だった46歳の人が、note起点で103,000円を作りました
    → 自分と遠くない誰かの結果があると「自分にもできる」に変わる
```

### C4 高いしあとでいい

```
NG  今だけ50%オフの2,490円です
    → 安いほど「こんな値段で大丈夫か」と再現性の不安が増える

OK  この内容を人に教わると10万円かかります。今回は4,980円です。
    理由は、私自身がまだ検証中の部分を含むからです
    → 高さを認めた上で、安い理由に根拠がある
```

### C5 自分には早い

```
NG  初心者から上級者まで、すべての方におすすめです
    → 全員におすすめと書くほど、誰も自分ごとにしない

OK  これから始める人には早すぎます。
    少額でも0→1を突破していて、Claude Codeを入れている人向けです
    → 向かない人を書くと、向く人の確信が上がる
```

### C6 本当に結果が出るのか

```
NG  この1冊で、集客も執筆も販売もすべて解決します
    → 広げるほど信じてもらえない

OK  この記事では告知の自動化はできません。
    できるのは、ネタ探しの時間をゼロにすることだけです
    → 約束を狭くするほど信じてもらえる
```

## 6. 漏斗

### 断定する

```
NG  人によって合う方法は違うと思いますが、参考になれば幸いです
    → 迷わせた時点で、読者は決めるのをやめる

OK  設計が先です。実績は後からついてきます
```

### 外の選択肢を消す

```
NG  （他の方法に一切触れない）
    → 読者は後で自分で比較する。その手間を残すと離脱する

OK  習慣化アプリで解決しようとする人もいます。
    ただ、あれは「やる気の管理」であって「判断の削減」ではありません。
    減らすべきなのは意志力ではなく、1回に考える量です
```

### 出口を1つに

```
NG  ぜひ購入してください。Xのフォローもお願いします。
    LINEにも登録してください
    → 3つ置くと、人は全部やらない

OK  今日やることは1つです。この続きを読んでください
```

## 7. 締め

**必ず理想の未来で終える。**

```
NG  ※ 特典は予告なく終了する場合があります
    → 注意書きで終わっている

NG  以上、参考になれば幸いです
    → 何も残らない

OK  明日の朝、デスクに着いたとき、
    すでに「昨日の業界動向の3行要約」が手元にある状態から始まります
    → 読者の明日が具体的に見える
```
