note で伸びているアカウントを調査し、`knowledge/account.md` を生成します。

**ヒアリングはしません。** 調査データから機械的に決めます。

## 手順

1. **既存の設定を確認する**
   - `knowledge/account.md` が既にあれば、上書きしてよいか一度だけ確認する
   - 無ければそのまま進む

2. **`account-research` を実行**（`researcher` サブエージェント）
   - ユーザーがジャンルを指定していればそれを、していなければ
     AI技術・自動化 / ビジネススキル / 副業・収益化 の3つを比較する
   - 各ジャンル3〜5アカウントを解剖する
   - **フォロワー数では評価しない。** スキ率・投稿頻度・参入時期・有料noteの型で見る
   - → `research/accounts/{genre}.md`

3. **参入可否を判定する**
   - 4条件（道具型が売れている / 空白地帯3つ以上 / 週5本が成立 / 1年以内に伸びた例）
   - **すべて満たしたジャンルだけを ○ にする。** 甘い判定はこの後の全記事をずらす
   - ○ が1つもなければ、その旨を報告して停止する

4. **`account-design` を実行**
   - 主カテゴリ1つ＋サブカテゴリ2〜3つを確定
   - ペルソナを**行動で**書く（状態で書かない）
   - 投稿方針と「書かないこと」を決める
   - → `knowledge/account.md`

5. **報告**

## 報告の形式

```
アカウント設計が完了しました。

## 主カテゴリ
{1つ}

## サブカテゴリ
1. {名前}
2. {名前}
3. {名前}

## ペルソナ
{行動で書いた一文}
支払い意欲: {高/中/低}

## 判断の根拠
- 参入可否: ○（道具型が成立 / 空白地帯 {n}個 / 週{n}本の投稿例あり）
- 比較したジャンル: {n}個
- 却下したジャンル: {名前}（理由）

## 書かないこと
- {範囲外として明示したもの}

次: /note-daily で最初の記事を作れます。
ただし先に weekly-research で在庫を仕込む必要があります。
```

## 停止条件

以下は**停止して報告する**。推測で埋めない。

- 参入可否 ○ のジャンルが1つもない
- `profile.md` が存在しない
- 調査で有料noteの型を判定できなかった（道具型か体験談型か不明）
