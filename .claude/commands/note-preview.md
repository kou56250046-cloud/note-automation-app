投稿待ちの記事を HTML にして、コピペできる状態で開きます。

**ブラウザ自動操作は使いません。** 人間がコピーして note に貼ります。

## 手順

### 1. プレビューを生成する

```bash
node scripts/build-preview.mjs
```

`notes/*/meta.json` を持つ記事をすべて HTML にします。
このとき `lint.py` と `dedup.py` もローカルで実行し、結果をプレビューに埋め込みます。

**有料部分（`03-draft.md`）は GitHub Actions 上に存在しません**（`.gitignore` 対象）。
ここが有料noteを機械検査する唯一の機会です。

### 2. サーバーを起動する

```bash
node scripts/serve.mjs
```

`http://localhost:5173` が開きます。ポートが使用中なら `--port 5174` で変更します。

**`file://` で直接開かないでください。** `navigator.clipboard.write()` は
セキュアコンテキストを要求するため、書式つきコピーが動きません。

### 3. 使い方を伝える

ユーザーに以下を伝えます。

```
localhost:5173 を開きました。

## 無料記事
「本文をコピー」→ note のエディタに貼る → 公開

## 有料note
1. 「無料部分をコピー」→ note に貼る
2. note のエディタで有料エリアの境界線を設定する
3. 「有料部分をコピー」→ 境界線の下に貼る

見出し・太字・リスト・引用・区切り線は保持されます。
（クリップボードに text/html を書き込んでいるため）

投稿したら「投稿済みにする」を押してください。
ダッシュボードは localhost:5173/dashboard です。
```

## ゲートに引っかかっている記事があるとき

プレビュー画面に lint / dedup の結果が出ます。**エラーがある記事はそのまま貼らないでください。**

| 結果 | 対応 |
|---|---|
| lint エラー | `/note-revise {slug} "指摘内容"` で修正する |
| dedup が 0.85 超 | 切り口を変えるか、その記事を捨てる |
| dedup が 0.70〜0.85 | 判断して通す。`report.md` に記録されている |

## サーバーの止め方

`Ctrl+C` で終了します。起動したままでも害はありませんが、
`preview/` には有料本文が含まれるため、作業が終わったら止めるほうが安全です。

（`127.0.0.1` にバインドしているため、同一ネットワークの他端末からは見えません）
