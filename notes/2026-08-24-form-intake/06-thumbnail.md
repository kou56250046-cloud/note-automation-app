# 見出し画像のプロンプト

生成先: Gemini（画像生成）
比率: 16:9

## 判断

- 被写体: 7つの仕切りがある厚い金属製のトレイに、1本の太いパイプから液体が注ぎ込まれてい…（具体名詞。抽象概念を絵にしない）
- 色: 連載の基調（木曜デモ after.html の #3a9a5c を週の設計色として使用）
- 美学: 技術書の図版を極端に拡大したもの — 主題が「どの列を持つか」という構造そのものであるため
- キーワード: 「入口で決まる」（6文字）

## プロンプト

```
あなたは note の見出し画像を専門とするアートディレクターです。
以下の条件で16:9の画像を1枚作ってください。

## テキスト（これが主役・最優先）

「入口で決まる」を画像内に配置してください。

・**画面の6割以上を文字が占める大きさ**にする
・極太のゴシック体（Black / Heavy 相当）。細い書体を使わない
・文字を **8度 傾ける**。水平に置かない
・文字の背後に強い光源を置き、縁が光って見えるようにする
・文字色は #ffffff。背景とのコントラストを最大にする
・被写体に重なっても構わない。**文字を避けて配置しない**
・縮小表示でも読めることを最優先する

## 被写体（文字の背景として置く）

7つの仕切りがある厚い金属製のトレイに、1本の太いパイプから液体が注ぎ込まれている。仕切りの4番目だけが内側から光っている

・文字の背後に置く。主役は文字である
・縁を光らせる（エッジライト）

## 色（3色まで。全部を強くする）

・背景: #0d0d10。明度を極端に振る（ほぼ黒）
・文字: #ffffff
・アクセント: #3a9a5c。**1色だけ、面で使う**（線で使わない）
・中間色・くすみ色・パステルを使わない。縮小すると灰色になる

## 質感とライティング

・技術書の図版を極端に拡大したもの
・**強い一灯**。真横からのリムライト1つだけ
・影は硬く、濃く。柔らかい影は縮小すると消える
・高精細、ノイズなし、4K品質

## 避けるもの

・全面に敷くグラデーション
・複数の光源で影の方向がばらつくこと
・要素を3つ以上並べること
・爆発・炎・稲妻・札束・王冠
・画像内に煽り文句を書くこと
・Googleフォームの画面を模したUI、書類のアイコン、脳のイラスト、光る回路基板
```

## 生成後の確認

- [ ] **サムネの大きさまで縮小しても、キーワードが読めるか**（最重要）
- [ ] 文字が画面の6割以上を占めているか
- [ ] 文字が傾いているか（水平に整列していないか）
- [ ] 中間色に逃げていないか。3色が全部強いか
- [ ] 記事のデモと色が揃っているか
- [ ] **画像内に煽り文句が入っていないか**（voice.md の ng は画像にも適用する）
