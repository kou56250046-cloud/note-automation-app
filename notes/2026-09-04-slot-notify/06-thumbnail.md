# 見出し画像のプロンプト

生成先: Gemini（画像生成）
比率: 16:9

## 判断

- 被写体: 暗い部屋の壁に掛かった1つの時計。その針が指す先から、1本だけ光の線が伸びて画面の外へ抜けていく（具体名詞。抽象概念を絵にしない）
- 色: `account.md` サブカテゴリ2（自動化フローの設計思想）から決定。デモが無い記事のため、連載の基調色（青）に合わせた
- 美学: ポスターアート（映画・音楽フェスの告知） — 「締切に1回だけ」という判断そのものが主題で、文字が主役になる記事であるため
- キーワード: 「締切に1回」（5文字）

## プロンプト

```
あなたは note の見出し画像を専門とするアートディレクターです。
以下の条件で16:9の画像を1枚作ってください。

## テキスト（これが主役・最優先）

「締切に1回」を画像内に配置してください。

・**画面の6割以上を文字が占める大きさ**にする
・極太のゴシック体（Black / Heavy 相当）。細い書体を使わない
・文字を **10度 傾ける**。水平に置かない
・文字の背後に強い光源を置き、縁が光って見えるようにする
・文字色は #ffffff。背景とのコントラストを最大にする
・被写体に重なっても構わない。**文字を避けて配置しない**
・縮小表示でも読めることを最優先する

## 被写体（文字の背景として置く）

暗い部屋の壁に掛かった1つの時計。その針が指す先から、1本だけ光の線が伸びて画面の外へ抜けていく

・文字の背後に置く。主役は文字である
・縁を光らせる（エッジライト）
・時計以外の光源を置かない。**線は1本だけ**にする。何度も鳴らないことが主題である

## 色（3色まで。全部を強くする）

・背景: #0a0d12。明度を極端に振る（ほぼ黒）
・文字: #ffffff
・アクセント: #2f7de1。**1色だけ、面で使う**（線で使わない）
・中間色・くすみ色・パステルを使わない。縮小すると灰色になる

## 質感とライティング

・ポスターアート（映画・音楽フェスの告知）
・**強い一灯**。真横からのリムライト1つだけ
・影は硬く、濃く。柔らかい影は縮小すると消える
・高精細、ノイズなし、4K品質

## 避けるもの

・全面に敷くグラデーション
・複数の光源で影の方向がばらつくこと
・要素を3つ以上並べること
・爆発・炎・稲妻・札束・王冠
・画像内に煽り文句を書くこと
・円グラフ、棒グラフ、折れ線グラフ、既製のダッシュボードUIキット風の絵、メーター表示
```

## 生成後の確認

- [ ] **サムネの大きさまで縮小しても、キーワードが読めるか**（最重要）
- [ ] 文字が画面の6割以上を占めているか
- [ ] 文字が傾いているか（水平に整列していないか）
- [ ] 中間色に逃げていないか。3色が全部強いか
- [ ] 記事のデモと色が揃っているか
- [ ] **画像内に煽り文句が入っていないか**（voice.md の ng は画像にも適用する）
