# 見出し画像のプロンプト

生成先: Gemini（画像生成）
比率: 16:9

## 判断

- キーワード: **「毎回、同じ色」**（7文字。商品の約束を最短で言い切った）
- 被写体: 同じ画面が5枚、奥へ重なって並んでいる。**5枚とも寸分違わず同じ色**
- 色: 背景 `#08080c`（ほぼ黒）／文字 `#ffffff`／アクセント `#3b6ef6`（`tokens.css` の `--color-accent`）
- 美学: **強コントラストのプロダクト写真**（黒背景＋強い一灯）
- 傾き: 文字を 9度 傾ける

**有料noteなのでタイムラインで最も目立たせる。** アクセントは商品そのものの
`--color-accent: #3b6ef6` を使い、**買った人が手に入れる色をサムネで見せる。**

無料記事のサブ①2本（月曜=藍 `#2456e0` / 金曜=藍＋赤茶）とは色が近いので、
**枚数の反復**（5枚が奥へ整列する構図）で差をつける。あちらは横並び、こちらは奥行き。

## プロンプト

```
あなたは note の見出し画像を専門とするアートディレクターです。
以下の条件で16:9の画像を1枚作ってください。

## テキスト（これが主役・最優先）
「毎回、同じ色」を画像内に配置してください。

・画面の6割以上を文字が占める大きさにする
・極太のゴシック体（Black / Heavy 相当）。細い書体を使わない
・文字を9度、右上がりに傾ける。水平に置かない
・文字の背後から強い光が差し、文字の縁が青く光って見えるようにする
・文字色は #ffffff、縁の発光は #3b6ef6
・背後のパネルに重なっても構わない。文字を避けて配置しない
・縮小表示でも読めることを最優先する

## 被写体（文字の背景として置く）
同じ形のパネルが5枚、手前から奥へ少しずつ小さくなりながら重なって並んでいる。

・5枚とも、面の色と縁の色が完全に一致している。1枚も色がずれていない
・各パネルの中には、同じ位置に同じ大きさの矩形が3つずつ配置されている
・矩形の1つだけが鮮やかな青で、それも5枚すべてで同じ位置にある
・パネルに文字やアイコンを描き込まない
・パネルの縁が青く光っている（エッジライト）
・奥へ向かう反復のリズムを強く出す
・文字の背後に置く。主役は文字である

## 色（3色まで。全部を強くする）
・背景: #08080c（ほぼ黒）
・文字: #ffffff
・アクセント: #3b6ef6（青）。5枚の縁と、各パネルの矩形1つに面で使う
・中間色・くすみ色・パステルを使わない
・青は最大彩度で発光させる。淡い水色にしない

## 質感とライティング
・黒背景に強い一灯を当てたプロダクト写真
・強い一灯。左上からのリムライトでパネルの縁を光らせる
・影は硬く、濃く。手前のパネルが奥へ落とす影の輪郭をはっきり出す
・高精細、ノイズなし、4K品質

## 避けるもの
・全面に敷くグラデーション
・複数の光源で影の方向がばらつくこと
・5枚のパネルの色を1枚でも変えること（**記事の主題と正反対になる**）
・爆発・炎・稲妻・札束・王冠
・画像内に「毎回、同じ色」以外の文字を書くこと
・脳のイラスト、光る回路基板、ロボットの手、青い網目状のネットワーク
・カラーパレット、カラーホイール、絵の具、筆
```

## 生成後の確認

- [ ] **200px 幅に縮めても「毎回、同じ色」が読めるか**（最重要）
- [ ] 文字が画面の6割以上を占めているか
- [ ] 文字が9度傾いているか
- [ ] **5枚のパネルが完全に同じ色か**（1枚でもずれていたら作り直す。主題と正反対になる）
- [ ] 青が淡い水色になっていないか（最大彩度か）
- [ ] 画像内に煽り文句が入っていないか
