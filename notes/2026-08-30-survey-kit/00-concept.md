## 3要素

- **強み**: `account.md` サブカテゴリ③「差し替えて使う自動化テンプレート — 完成品を渡す」のど真ん中。完成したシステム一式を、差し替え箇所だけ書いて配る形そのもの
- **競合の穴**: `market/2026-08-24.md` の実測より。`GAS` は需要207.0 / 供給32.9件/日で比 **6.301**、有料率 **11%**。`GoogleAppsScript` は比 **4.407**、有料率 **10%**。`GeminiAPI` は比 **21.446**（需要27.0 / 供給1.3件/日）で計測タグ中1位。クラスタ **#6**（プロンプト / AI / マジクラ、35記事、スキ中央値 **206**、比 **5.8857**、主なタグ GoogleWorkspace・GAS）は「型を渡すテンプレート」が強く読まれる帯である。**GAS 領域で有料が成立している一方、アンケート自由記述という具体的な業務に対して完成版一式を渡す商品は、この計測範囲の上位例に見当たらない**

## 渡すもの

- **形式**: GAS コード（.gs）＋ HTML Service のテンプレート（.html）＋ プロンプト全文（Markdown）＋ 差し替え表（Markdown）
- **点数**:
  - GAS コード **5ファイル**（入口 `intake.gs` / 中核 `summarize.gs` / 失敗対策 `guard.gs` / 通知 `notify.gs` / 設定 `config.gs`）
  - HTML Service **1画面**（`index.html`。CSS・JS をインラインで自己完結）
  - プロンプト **1本**（要約・カテゴリ・感情スコアを1回で返す）＋ `responseSchema` 定義 **1本**
  - 差し替え表 **1枚**（差し替え箇所 全7項目）
- **動作条件**:
  - Google アカウント（Google フォーム＋スプレッドシートが使えること）
  - Gemini API キー（スクリプトプロパティ `GEMINI_API_KEY` に登録）
  - Slack Incoming Webhook URL（**任意**。無くても通知以外は動く）
  - Apps Script の実行権限を承認できること（外部 API を叩くため、シンプルトリガーでは動かない）
- **最初の1歩**: スクリプトプロパティに `GEMINI_API_KEY` を登録し、`setupFormTrigger()` を1回だけ手動実行する。フォームに1件テスト回答を入れて、シートに要約が書かれることを確認する
- **できないこと**:
  - **日本語以外の自由記述**は検証していない。プロンプトが日本語前提である
  - **Slack 以外の通知先**（メール / LINE / Chatwork）は含まない。`notify.gs` の POST 先を差し替える必要がある
  - **感情スコアの絶対値に意味を持たせていない。** 閾値で相対的に絞るための数値であり、心理尺度ではない
  - **回答が1回の実行で大量に届く場合のバッチ分割**は含まない。GAS の6分制限に当たる規模では別途分割が要る
  - **フォームの設問設計そのもの**は扱わない。自由記述が1問ある前提

## 構成

### 無料部分（`02-letter.md` / 2000字）

**出し惜しみしない。** 道具型で C2（再現性がなさそう）が落ちるのは中身を隠したときである。

見せる実物の断片:

- **プロンプト全文の冒頭 8行程度**（役割指定とカテゴリ列挙の部分まで。出力形式の指定は有料側）
- **差し替え表の 7項目のうち 3項目**（シート名 / カテゴリ一覧 / 感情スコアの閾値）を、実際の記述例つきで
- **ダッシュボードのスクリーンショットではなく、木曜記事の公開デモURL**（すでに無料で見られるものを示す）

「1割を見せて9割を渡す」の比率に沿う。

### 有料部分（`03-draft.md` / 5000〜8000字）

1. 全体の流れと5ファイルの責務（どのファイルが何を持つか）
2. `config.gs` — 差し替え箇所を1ファイルに集約する設計と、その全文
3. `intake.gs` — フォーム受信とシート書き込み。処理状態列の設計と全文
4. `summarize.gs` — プロンプト全文・`responseSchema` 全文・Gemini 呼び出しの全文
5. `guard.gs` — LockService による排他と 429 の指数バックオフの全文
6. `notify.gs` — 閾値による絞り込みと Slack POST の全文
7. `index.html` — カード型ダッシュボードの全文（CSS・JS インライン）
8. **差し替え手順書** — 全7項目を、どのファイルの何行目を何に変えるかまで
9. 動かないときに最初に見る3箇所
10. できないことと、その回避方法

## 対象読者

`account.md` のペルソナを、この商品に合わせて絞ったもの。

**GAS でアンケートや問い合わせの集計を自分用に組んだが、結果を人に共有する段になって「シートを見て」としか言えていない人。**

- コードは自分で書ける。書けないから買うのではない
- **自分で組むより速いと感じられなければ払わない**（`account.md` 191行目）
- Gemini API を触ったことはあるが、出力の形が毎回ぶれて後段が壊れた経験がある
- 「その仕組み使わせて」と言われたときに、渡す形になっていない

**外す読者**: 自動化に興味があるだけでまだ何も組んでいない人。この商品は差し替えて使う前提であり、GAS エディタを開いたことがない人には早い。
