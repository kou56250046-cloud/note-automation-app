# 見出し画像のプロンプト

生成先: Gemini（画像生成）
比率: 16:9

## 判断

- 被写体: 4枚の板状の部品と1枚の画面パネルが、宙に浮いたまま1つの装置に組み上がる途中の分解図。装置の正面には5列3行の格子が光っている（具体名詞。抽象概念を絵にしない）
- 色: **notes/2026-09-03-heatmap-view/demo/after.html から取得**（#1d1d1f / 濃い青 / #d4a017）。連載の完成版であることを示すため、デモで「全員空き」に使う金 #d4a017 を面で使う
- 美学: ポスターアート（映画・音楽フェスの告知） — 完成版一式を渡すという商品そのものが主題で、文字が主役になる記事であるため
- キーワード: 「一式で渡す」（5文字）

## プロンプト

```
あなたは note の見出し画像を専門とするアートディレクターです。
以下の条件で16:9の画像を1枚作ってください。

## テキスト（これが主役・最優先）

「一式で渡す」を画像内に配置してください。

・**画面の6割以上を文字が占める大きさ**にする
・極太のゴシック体（Black / Heavy 相当）。細い書体を使わない
・文字を **8度 傾ける**。水平に置かない
・文字の背後に強い光源を置き、縁が光って見えるようにする
・文字色は #ffffff。背景とのコントラストを最大にする
・被写体に重なっても構わない。**文字を避けて配置しない**
・縮小表示でも読めることを最優先する

## 被写体（文字の背景として置く）

4枚の板状の部品と1枚の画面パネルが、宙に浮いたまま1つの装置に組み上がる途中の分解図。装置の正面には5列3行の格子が光っている

・文字の背後に置く。主役は文字である
・縁を光らせる（エッジライト）
・部品は4枚と画面1枚の**合計5点だけ**を置く。数が数えられる絵にする

## 色（3色まで。全部を強くする）

・背景: #12100c。明度を極端に振る（ほぼ黒）
・文字: #ffffff
・アクセント: #d4a017。**1色だけ、面で使う**（線で使わない）
・中間色・くすみ色・パステルを使わない。縮小すると灰色になる

## 質感とライティング

・ポスターアート（映画・音楽フェスの告知）
・**強い一灯**。真横からのリムライト1つだけ
・影は硬く、濃く。柔らかい影は縮小すると消える
・高精細、ノイズなし、4K品質

## 避けるもの

・全面に敷くグラデーション
・複数の光源で影の方向がばらつくこと
・要素を3つ以上並べること
・爆発・炎・稲妻・札束・王冠
・画像内に煽り文句を書くこと
・円グラフ、棒グラフ、折れ線グラフ、既製のダッシュボードUIキット風の絵、メーター表示
```

## 生成後の確認

- [ ] **サムネの大きさまで縮小しても、キーワードが読めるか**（最重要）
- [ ] 文字が画面の6割以上を占めているか
- [ ] 文字が傾いているか（水平に整列していないか）
- [ ] 中間色に逃げていないか。3色が全部強いか
- [ ] 記事のデモと色が揃っているか
- [ ] **画像内に煽り文句が入っていないか**（voice.md の ng は画像にも適用する）
