---
description: 完成した記事に差し戻し指示を出して再生成する
---

`notes/$1/` の記事を、指示 `$2` に従って修正します。

**最初から作り直しません。** 指示された箇所だけを直します。

## 手順

### 1. 対象を特定する

| `meta.json` の `type` | 修正するファイル |
|---|---|
| `free` | `02-final.md`（無ければ `01-draft.md`） |
| `paid` | 指示の内容で判断する（レターなら `02-letter.md`、本文なら `03-draft.md`） |

`notes/$1/` が存在しなければ停止して報告します。

### 2. 指示を分類する

| 指示の種類 | 対応 |
|---|---|
| 文体・表現の修正 | 該当箇所だけを直す |
| 構成の変更 | 影響範囲を明示してから直す |
| 事実・数字の追加 | **`profile.md` に根拠があるか確認する。無ければ書かずに報告する** |
| テーマそのものの変更 | 修正ではなく別記事にすべき。その旨を伝えて確認する |

### 3. 修正する

**指示された箇所だけを直してください。** 周辺の文章を書き換えないこと。

○だった箇所を壊すと、通過していたゲートが再び×になります。

### 4. ゲートを再実行する

修正した内容によって、通すゲートが変わります。

| 修正内容 | 再実行するゲート |
|---|---|
| 表現・文体のみ | `lint.py`（ローカル） |
| 主張・事実を含む | **`ethics-line` を必ず再実行**（上限なし） |
| レターの構造 | `letter-audit`（残り回数の範囲で） |
| 大幅な書き換え | すべて |

**`ethics-line` は迷ったら実行してください。** 法的リスクは修正の大小と無関係です。

### 5. 報告

```
修正しました — $1

## 変更箇所
- L{n}: {何を、なぜ}

## 再実行したゲート
- lint.py: エラー {n} 件 → 0 件
- ethics-line: 検出なし

## 変更しなかったこと
- 「{指示の一部}」: profile.md に根拠がないため書けませんでした
```

## 断ること

以下は修正せず、理由を伝えて停止します。

- **`profile.md` に根拠のない実績・数字の追加**
- **`account.md` のカテゴリ範囲を出る内容への変更**
- **`voice.md` の禁止表現を使う指示**

ユーザーが再度同じ指示を出した場合は、**まず `profile.md` か `voice.md` を更新するよう促してください。**
記事だけを例外にすると、次の記事から同じ判断ができなくなります。
