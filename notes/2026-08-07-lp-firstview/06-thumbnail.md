# 見出し画像のプロンプト

生成先: Gemini（画像生成）
比率: 16:9

## 判断

| 項目 | 決めたもの | 根拠 |
|---|---|---|
| 被写体 | 暗い机の上に立てかけられた**2枚の薄いガラス板** | 記事が before/after の対比なので、2つ並ぶ絵で「比較の記事」だと伝わる |
| 色 | 背景 `#12111b` / アクセント `#ffb43d` | **`demo/after.html` の `:root` から取った。** 記事のデモとサムネの色を揃える |
| 美学 | **プロダクト写真**（1つだけ） | 成果物（画面そのもの）を見せる記事のため。編集写真・図解は選ばない |

## プロンプト

```
あなたは note の見出し画像を専門とするアートディレクターです。
以下の条件で16:9の画像を1枚作ってください。

## 被写体（最重要）
暗い作業机の上に、2枚の薄いガラス板が少し間隔をあけて立てかけられている。
・手前の板：琥珀色に発光する小さな立方体が整然と格子状に並んでいる。輪郭がはっきりしている
・奥の板：紫と青の光がにじんでいて、形が曖昧。ピントが合っていない
2枚の板は同じ大きさ・同じ角度で、手前が主役だと分かる配置。

## 構図
・2枚の板を画面の左寄りに配置する
・右側の約4割を、平坦で暗い余白として空ける
・視線が奥の板から手前の板へ自然に移動する角度
・浅い被写界深度。奥の板と背景は軽くぼかす

## 色
・背景の基調: #12111b（わずかに紫を含む暗色）
・アクセント: #ffb43d（琥珀）。この1色だけを使う
・コントラストを強く。中間色を多用しない
・紫はぼけた奥の板にだけ許可する

## 質感とライティング
・Apple の製品ページのようなプロダクト写真
・斜め右上からの単一光源。影の方向をすべて揃える
・ガラスの厚みと縁の反射を描写する
・高精細、ノイズなし、4K品質

## テキスト
画像内に文字を一切入れないでください。
note ではタイトルが画像の上に重なるため、
右側に文字を置ける平坦な余白を確保してください。

## 避けるもの
・グラデーションを全面に敷くこと
・複数の光源で影の方向がばらつくこと
・要素を3つ以上並べること
・脳のイラスト、光る回路基板、ロボットの手、青い網目状のネットワーク
・ノートPCの前に座る人物
・カラフルなUIパーツが空中に散乱している構図
・板の中に実際の文字やUIラベルを描き込むこと
```

## 生成後の確認

- [ ] 画像内に文字が入っていないか
- [ ] 右側にタイトルを置ける余白があるか
- [ ] 琥珀（#ffb43d）が記事のデモと揃っているか
- [ ] 手前の板が主役だと一目で分かるか
