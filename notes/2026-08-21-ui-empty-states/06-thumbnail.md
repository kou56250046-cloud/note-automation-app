# 見出し画像のプロンプト

生成先: Gemini（画像生成）
比率: 16:9

## 判断

- 被写体: 生成り色の机に置かれた**4枚の薄いパネル**。左端の1枚だけが行の並んだ一覧画面で、
  右の3枚は中身が空・回転する短い弧・欠けた形の3種になっている。
  **AI が作るのは左の1枚だけで、右の3枚は自分で足すもの**という記事の構造をそのまま並べた
- 色: `demo/after.html` の `:root` から取得
  （`--paper: #f6f3ec` / `--ink: #221f19` / `--accent: #2456e0` / `--bad: #a24a42`）。
  **`--bad` を使うのはこの記事だけ**で、エラー状態を扱うことがひと目で分かる
- 美学: プロダクト写真（Appleの製品ページのような質感）。
  同じ月曜のサブ①（`2026-08-17-dashboard-3points`）が計測器の質感を使うため、
  こちらは平面のパネルに寄せて質感で分けた
- キーワード: 「3画面足りない」（7文字。数と欠落を同時に言い切った）

**`2026-08-11-ui-3points` とは枚数で差をつけている。** あちらは2枚の対比（before/after）、
こちらは1枚＋3枚（足りない分を並べる）。並んだときに構図が別物に見える。

## プロンプト

```
あなたは note の見出し画像を専門とするアートディレクターです。
以下の条件で16:9の画像を1枚作ってください。

## 被写体（最重要）
生成り色の紙を敷いた机の上に、同じ大きさの薄いパネルが4枚、横一列に置かれている。
・左端の1枚: 横線が均等に7本引かれている（データが並んだ一覧を表す）。完成した状態
・2枚目: 面が完全に無地。中央に小さな四角の枠だけがある
・3枚目: 中央に短い弧が1本だけ描かれている（回転の途中のような形）
・4枚目: 面の一部が欠けていて、欠けた縁だけが濃い赤茶色になっている
どのパネルにも文字やアイコンを描き込まない。線と形と欠けだけで見せる。
左端の1枚だけがわずかに手前に、残りの3枚は少しだけ奥に引いて置く。

## 構図
・4枚を横一列に等間隔で並べ、左端の1枚と右の3枚のあいだだけ間隔を広めに取る
・画面上部の3割を平坦な余白として空ける
・浅い被写界深度。左端のパネルにピントを合わせ、右へ行くほどわずかにぼかす

## 色
・背景の基調: #f6f3ec（生成りの紙）
・インク: #221f19。パネルの縁と、左端の横線に使う
・中間色: #85796a。2枚目の四角の枠と3枚目の弧に使う
・アクセント: #2456e0（藍）。左端のパネルの縁にだけ細く使う
・警告色: #a24a42（赤茶）。4枚目の欠けた縁にだけ使う。他には一切使わない
・コントラストを強く。中間色を多用しない

## 質感とライティング
・Appleの製品ページのようなプロダクト写真
・斜め上からの単一光源。影の方向をすべて揃える
・パネルの薄さ、机との隙間に落ちる細い影を丁寧に描写する
・4枚目の欠けた断面には、わずかに厚みが見える
・高精細、ノイズなし、4K品質

## テキスト（必須・大きく主張する）
画面上部の余白に「3画面足りない」というキーワードを大きく配置してください。

・太い書体（Bold/Black相当）で、パネルと同じかそれ以上の視覚的な強さで配置する
・「3」の文字だけ #a24a42（赤茶）にし、残りは #2456e0（藍）にする
・#f6f3ec の背景とのコントラストを最優先する
・文字の縁取りや薄いドロップシャドウで可読性を確保する。背景に溶け込ませない
・右の3枚のパネルの上端に揃えて配置し、パネルの並びと一体化させる
```
