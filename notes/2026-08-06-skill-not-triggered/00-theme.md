# 「スキルが起動しない・呼ばれない」を3手順で切り分ける

themes.md の id: 2026-W32-01
type: free / 本来の曜日: mon / サブカテゴリ: トラブルシューティング

## 今日これを選んだ理由

本来は木曜（有料note）の日だが、有料noteのフローに必要なスキル
（product-concept / draft-writing / title-design）が未実装のため、
月曜の無料記事を繰り上げた。

先に無料記事のフローを1本通し、トークン消費の実測を取ることを優先する。

## 選定理由（themes.md の rationale）

strength5: account.md のペルソナ「frontmatter を3回書き直した人」に直接対応する。
working directory のスコープ、frontmatter のキー表記ゆれ、description の文字数上限、
model パラメータがスラッシュ起動でしか効かない、サブエージェントのセッション上限といった
具体的な原因が複数の一次情報で確認できており、手元の材料だけで書ける。

market4: 「スキルの作り方」記事は多数あるが、起動しない/呼ばれないケースを
切り分け手順としてまとめた記事は見当たらなかった（ai-tech.md 空白地帯1と符合）。

willingness2: 無料記事想定。情報を知れば手元で直せる内容。

次点: 「Claude Code Skills の書き方完全ガイド」は情報量が多いが、主題が「作り方」であり
account.md の禁止事項（入門・インストール手順）に抵触するため候補から外した。

## 切り口（angle）

「原因一覧」ではなく「上から順に確認する3手順」の形にする。
ai-tech.md で確認した3アカウントはいずれも成功事例中心で、
失敗の切り分けフローを持つ記事がない点で差別化する。
