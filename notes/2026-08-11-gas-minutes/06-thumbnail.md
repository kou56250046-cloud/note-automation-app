# 見出し画像のプロンプト

生成先: Gemini（画像生成）
比率: 16:9

## 判断

- 被写体: スプレッドシートの表。左列に長い文章の行が並び、右列で同じ行が短く畳まれている（議事録→要約の変換を「行の長さの違い」で見せる）
- 色: `demo/after.html` が無いため、account.md のサブ①デモで既に使用している基調色（背景 #12111b・アンバー #ffb43d）をアカウント全体の統一色として採用
- 美学: 図解（技術書の図版）。手順・変換のフローが主題のため
- キーワード: 「議事録、要約する。」（記事タイトルの核心部分を短く言い切った形）

## プロンプト

```
あなたは note の見出し画像を専門とするアートディレクターです。
以下の条件で16:9の画像を1枚作ってください。

## 被写体（最重要）
スプレッドシートのような表構造。左側の列には長く詰まったテキストの行が5〜6行並び、
右側の列には同じ行が短く畳まれた形で並んでいる。行と行の間に、左から右へ向かう
細い矢印か接続線を1本だけ描き、「長い行が短い行に変換されている」ことを示す。

## 構図
・画面下半分に表全体を配置し、上半分をキーワードのための余白にする
・視線が左の長い行から右の短い行へ、そしてキーワードへと自然に流れる配置
・浅い被写界深度。表部分の背景は軽くぼかす

## 色
・背景の基調: #12111b（濃いダークネイビー系）
・アクセント: #ffb43d（アンバー）。矢印・畳まれた行のハイライト・キーワードの文字色に使う。1色だけ
・コントラストを強く。中間色を多用しない

## 質感とライティング
・技術書の図版のような、線と面で構成されたフラットな図解
・斜め上からの単一光源。影の方向を揃える
・高精細、ノイズなし、4K品質

## テキスト（必須・大きく主張する）
画面上半分に「議事録、要約する。」というキーワードを大きく配置してください。

・太い書体（Bold/Black相当）で、下の表と同じかそれ以上の視覚的な強さで配置する
・文字色は #ffb43d（アンバー）で統一し、#12111b の背景とのコントラストを最優先する
・文字の縁取りや薄いドロップシャドウで可読性を確保する。背景に溶け込ませない
・デザイン性を最優先する。ただの文字の貼り付けではなく、下の表の図解と一体化した
  タイポグラフィとして配置する

## 避けるもの
・グラデーションを全面に敷くこと
・複数の光源で影の方向がばらつくこと
・要素を3つ以上並べること
・脳のイラスト、光る回路基板、ロボットの手、青い網目状のネットワーク
・歯車やギアのモチーフ（自動化の紋切り型表現）
・キーワードが背景に埋もれて読みにくくなること
```

## 生成後の確認

- [ ] キーワードが大きく・高コントラストで、下の図解と同等以上に目立っているか
- [ ] 文字が背景に溶け込まず読み取れるか
- [ ] 記事のデモと色が揃っているか（デモ無し。アカウント基調色との整合のみ確認）
