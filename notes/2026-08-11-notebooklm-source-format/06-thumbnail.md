# 見出し画像のプロンプト

生成先: Gemini（画像生成）
比率: 16:9

## 判断

- 被写体: 開かれた1冊のノート。左のページはべた書きの手書き文字がぎっしり詰まっている。右のページは見出しと短い項目が整然と並んでいる（同じ情報量でも、構造化されているかどうかが違う、という記事の主題を1冊のノートの見開きで見せる）
- 色: `demo/after.html` が無いため、account.md のサブ①デモ・2026-08-11-gas-minutesで使用済みの基調色（背景 #12111b・アンバー #ffb43d）をアカウント全体の統一色として採用
- 美学: 図解（技術書の図版）。ソースの構造化という手順が主題のため
- キーワード: 「入れる前に、整える」（8文字程度。記事タイトルの核心を短く言い切った形）

## プロンプト

```
あなたは note の見出し画像を専門とするアートディレクターです。
以下の条件で16:9の画像を1枚作ってください。

## 被写体（最重要）
暗い机の上に開かれた1冊のノートの見開き。
・左のページ: 細い線がびっしり詰まった、べた書きの文章のような密度の高いテクスチャ
・右のページ: 短い横線のブロックが見出しと項目のように整然と並び、余白がある
どちらのページにも実際の文字やUIラベルは描き込まない。密度と余白の対比だけで見せる。

## 構図
・ノートの見開きを画面下半分に配置し、上半分をキーワードのための余白にする
・視線が左のページから右のページへ、そしてキーワードへ流れる配置
・浅い被写界深度。ノートの縁はわずかにぼかす

## 色
・背景の基調: #12111b（濃いダークネイビー系）
・アクセント: #ffb43d（アンバー）。右のページの見出しブロックとキーワードの文字色に使う。1色だけ
・コントラストを強く。中間色を多用しない

## 質感とライティング
・技術書の図版のような、平面的で情報が読み取りやすい図解
・斜め上からの単一光源。影の方向を揃える
・高精細、ノイズなし、4K品質

## テキスト(必須・大きく主張する)
画面上半分に「入れる前に、整える」というキーワードを大きく配置してください。

・太い書体（Bold/Black相当）で、下のノートと同じかそれ以上の視覚的な強さで配置する
・文字色は #ffb43d（アンバー）で統一し、#12111b の背景とのコントラストを最優先する
・文字の縁取りや薄いドロップシャドウで可読性を確保する。背景に溶け込ませない
・デザイン性を最優先する。ただの文字の貼り付けではなく、下のノートの対比構図と一体化した
  タイポグラフィとして配置する

## 避けるもの
・グラデーションを全面に敷くこと
・複数の光源で影の方向がばらつくこと
・要素を3つ以上並べること
・脳のイラスト、光る回路基板、ロボットの手、青い網目状のネットワーク
・ページに実際の文字やUIラベルを描き込むこと
・キーワードが背景に埋もれて読みにくくなること
```

## 生成後の確認

- [ ] キーワードが大きく・高コントラストで、下のノートと同等以上に目立っているか
- [ ] 文字が背景に溶け込まず読み取れるか
- [ ] 記事のデモと色が揃っているか（デモ無し。アカウント基調色との整合のみ確認）
