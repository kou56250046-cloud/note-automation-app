# 見出し画像のプロンプト

生成先: Gemini（画像生成）
比率: 16:9

## 判断

- キーワード: **「調べ直さない」**（6文字。商品が消す作業を1語で言い切った）
- 被写体: 散らばった点を1本の太い線が貫き、通った点だけが発光して残っている
- 色: 背景 `#050a08`（ほぼ黒）／文字 `#ffffff`／アクセント `#00ffc2`（蛍光ミント）
- 美学: **ポスターアート**（映画の告知）。線が画面を斜めに割る構図
- 傾き: 文字を 11度 傾ける

**同じサブ③の水曜（`notebooklm-conflict`）とは明度を反転させている。**
あちらは白背景＋蛍光レッド。こちらは黒背景＋蛍光ミント。
水曜が「点」（質問1つ）、日曜が「線」（入口から出口まで）という記事の関係が、
そのまま被写体の差になっている。

## プロンプト

```
あなたは note の見出し画像を専門とするアートディレクターです。
以下の条件で16:9の画像を1枚作ってください。

## テキスト（これが主役・最優先）
「調べ直さない」を画像内に配置してください。

・画面の6割以上を文字が占める大きさにする
・極太のゴシック体（Black / Heavy 相当）。細い書体を使わない
・文字を11度、右上がりに傾ける。水平に置かない
・文字の背後から強い光が差し、文字の縁がミントグリーンに光って見えるようにする
・文字色は #ffffff、縁の発光は #00ffc2
・背後の線や点に重なっても構わない。文字を避けて配置しない
・縮小表示でも読めることを最優先する

## 被写体（文字の背景として置く）
暗い画面に小さな点が不規則に散らばっている。
その中を、太い1本の線が左下から右上へ斜めに貫いている。

・線が通過した点だけが、ミントグリーンに強く発光している
・線から外れた点は暗いまま、ほとんど見えない
・線は途中で切れず、画面の端から端まで1本でつながっている
・線は分岐しない。枝分かれを描かない
・点にも線にも文字や数字を描き込まない
・線の縁が発光している（エッジライト）
・文字の背後に置く。主役は文字である

## 色（3色まで。全部を強くする）
・背景: #050a08（ほぼ黒）
・文字: #ffffff
・アクセント: #00ffc2（蛍光ミント）。貫く線と、線上の点に面で使う
・中間色・くすみ色・パステルを使わない
・ミントは最大彩度で発光させる

## 質感とライティング
・映画の告知ポスター。線が画面を斜めに割る構成
・強い一灯。線そのものが光源になっている（自発光）
・影は硬く、濃く。線が背景に落とす光の滲みは最小限にする
・高精細、ノイズなし、4K品質

## 避けるもの
・全面に敷くグラデーション
・複数の光源で影の方向がばらつくこと
・線を分岐させること（**この記事は1本の線が主題である**）
・爆発・炎・稲妻・札束・王冠
・画像内に「調べ直さない」以外の文字を書くこと
・脳のイラスト、光る回路基板、ロボットの手、青い網目状のネットワーク
・本、書棚、虫眼鏡、書類の束、検索窓
```

## 生成後の確認

- [ ] **200px 幅に縮めても「調べ直さない」が読めるか**（最重要）
- [ ] 文字が画面の6割以上を占めているか
- [ ] 文字が11度傾いているか
- [ ] 線が1本でつながっていて、分岐していないか
- [ ] 水曜の `notebooklm-conflict`（白背景・レッド）と並べて明度が反転しているか
- [ ] 画像内に煽り文句が入っていないか
