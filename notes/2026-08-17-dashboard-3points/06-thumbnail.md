# 見出し画像のプロンプト

生成先: Gemini（画像生成）
比率: 16:9

## 判断

- 被写体: 生成り色の紙の上に、細い金属の棒が並んだ2つの列。左は棒の色がばらばらで、
  下端が宙に浮いている（軸が0から始まっていない状態を、棒が接地していないことで表す）。
  右は棒がすべて同じ色で、1本だけ藍色。全部が同じ台の上にきちんと接地している
- 色: `demo/after.html` の `:root` から取得（`--paper: #f6f3ec` / `--ink: #221f19` /
  `--accent: #2456e0` / `--ink-2: #85796a`）
- 美学: 実物の計測器・物差しの写真（工具や製図器具のカタログ写真の質感）。
  グラフの「目盛り」を主題にした記事のため、測る道具の手触りを借りる
- キーワード: 「目盛りを0に戻す」（8文字。3箇所のうち最も絵にしやすい1つを選んだ。
  色数と並びは棒の色と接地で同時に表現されるため、文字は目盛りに寄せた）

**同じ月曜のサブ①でも `2026-08-11-ui-3points` はカード（面）を被写体にしている。**
こちらは棒（線）にして、タイムライン上で並んでも別の記事に見えるようにした。

## プロンプト

```
あなたは note の見出し画像を専門とするアートディレクターです。
以下の条件で16:9の画像を1枚作ってください。

## 被写体（最重要）
生成り色の紙を敷いた台の上に、細長い金属の角棒が2つの列で並んでいる。
・左側: 6本の角棒。1本ずつ違う色に塗られている（赤、緑、紫、橙、水色、黄）。
  下端が揃っておらず、台から浮いて中途半端な高さで止まっている
・右側: 同じ6本の角棒。すべて同じ濃紺のグレーで、1本だけが藍色に塗られている。
  6本とも下端が台の面にぴたりと接地し、高さの差だけが見える
どちらの列にも数字や目盛りの文字を描き込まない。色と接地の有無だけで見せる。

## 構図
・左に「浮いた色とりどりの棒」、右に「接地した単色の棒」を置き、視線が左から右へ流れる
・画面上部の3割を平坦な余白として空ける
・真横やや上からの視点。棒の断面が少しだけ見える角度

## 色
・背景の基調: #f6f3ec（生成りの紙）
・インク: #221f19。台の縁と棒の影に使う
・中間色: #85796a。右側の棒の基本色
・アクセント: #2456e0（藍）。右側の1本にだけ使う
・左側の棒の彩度は高く、右側は藍以外を抑える。この対比を強く出す

## 質感とライティング
・工具や製図器具のカタログ写真。金属の梨地と塗装のマットな質感を描き分ける
・斜め上からの単一光源。影の方向をすべて揃える
・接地している棒には短く硬い影を、浮いている棒には離れた柔らかい影を落とす
・高精細、ノイズなし、4K品質

## テキスト（必須・大きく主張する）
画面上部の余白に「目盛りを0に戻す」というキーワードを大きく配置してください。

・太い書体（Bold/Black相当）で、棒と同じかそれ以上の視覚的な強さで配置する
・文字色は #2456e0（藍）で統一し、#f6f3ec の背景とのコントラストを最優先する
・文字の縁取りや薄いドロップシャドウで可読性を確保する。背景に溶け込ませない
・棒の並びと軸を揃えたタイポグラフィとして配置する。ただの貼り付けにしない
```
