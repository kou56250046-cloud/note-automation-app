## 同梱コードの実行確認

**weekly-build の要件「同梱するコードは抽出して実際に走らせて確認する」を実施した。**

`03-draft.md` から `validateAvailability_` と `findCommonSlots` を抽出し、
GAS の API（`SpreadsheetApp` / `Logger`）をモックした上で Node で 11 件のテストを走らせた。

**バグを2件検出し、修正した。**

1. **全員が全枠を「不可」と答えたとき、意味のない通知文が出ていた**
   `bestCount` が 0 でも最多枠の選択に進むため、「最も多くの人が空いているのは 月曜午前（0/2名）」と送っていた。
   受け取った側が動けない文面である。`bestCount === 0` の分岐を足し、
   「空いていると答えた人がいる枠が1つもありません／候補の曜日か時間帯を広げて、もう一度聞き直してください」を返すようにした。

2. **E列のJSONで曜日キーが欠けていると、通知処理ごと落ちていた**
   `JSON.parse` は成功するため try/catch をすり抜け、`availabilityList[j][day][slot]` で
   `Cannot read properties of undefined` になっていた。E列は手で書き換えられる場所である。
   `a[day] && a[day][slot]` の形に変え、欠けた回答者は「空いていない人」として扱うようにした。

**同じ関数は金曜の無料記事（2026-09-04-slot-notify）にも載っているため、そちらも同じ内容で修正した。**

修正後、11件すべて通過。全記事の JavaScript コードブロック17個を `node --check` に通し、構文エラー0件を確認した。
