# 見出し画像のプロンプト

生成先: Gemini（画像生成）
比率: 16:9

## 判断

- 被写体: 黒い金属のケースの中に、同じ素材の部品が6つ整列して収まっている。7番目の窪みに…（具体名詞。抽象概念を絵にしない）
- 色: 連載の基調色 #3a9a5c（月曜と揃え、週の始点と終点を同じ色で閉じる）
- 美学: 強コントラストのプロダクト写真（黒背景＋強い一灯） — 完成版一式という成果物そのものを渡す商品であり、実体を見せることが再現性の根拠になるため
- キーワード: 「6本を1つに」（6文字）

## プロンプト

```
あなたは note の見出し画像を専門とするアートディレクターです。
以下の条件で16:9の画像を1枚作ってください。

## テキスト（これが主役・最優先）

「6本を1つに」を画像内に配置してください。

・**画面の6割以上を文字が占める大きさ**にする
・極太のゴシック体（Black / Heavy 相当）。細い書体を使わない
・文字を **8度 傾ける**。水平に置かない
・文字の背後に強い光源を置き、縁が光って見えるようにする
・文字色は #ffffff。背景とのコントラストを最大にする
・被写体に重なっても構わない。**文字を避けて配置しない**
・縮小表示でも読めることを最優先する

## 被写体（文字の背景として置く）

黒い金属のケースの中に、同じ素材の部品が6つ整列して収まっている。7番目の窪みには、その6つが組み上がった1台の装置が置かれている。ケースの蓋の内側に、差し替え箇所を書いた1枚の金属プレートがねじ留めされている

・文字の背後に置く。主役は文字である
・縁を光らせる（エッジライト）
・**6つの部品と1台の完成品を1画面に収める。** 部品が同じ素材であることが分かるようにする

## 色（3色まで。全部を強くする）

・背景: #0d0d10。明度を極端に振る（ほぼ黒）
・文字: #ffffff
・アクセント: #3a9a5c。**1色だけ、面で使う**（線で使わない）
・中間色・くすみ色・パステルを使わない。縮小すると灰色になる

## 質感とライティング

・強コントラストのプロダクト写真（黒背景＋強い一灯）
・**強い一灯**。真横からのリムライト1つだけ
・影は硬く、濃く。柔らかい影は縮小すると消える
・高精細、ノイズなし、4K品質

## 避けるもの

・全面に敷くグラデーション
・複数の光源で影の方向がばらつくこと
・要素を3つ以上並べること
・爆発・炎・稲妻・札束・王冠
・画像内に煽り文句を書くこと
・札束、王冠、宝箱、リボン、ランキング風の装飾、「完全版」「保存版」などの文字
```

## 生成後の確認

- [ ] **サムネの大きさまで縮小しても、キーワードが読めるか**（最重要）
- [ ] 文字が画面の6割以上を占めているか
- [ ] 文字が傾いているか（水平に整列していないか）
- [ ] 中間色に逃げていないか。3色が全部強いか
- [ ] 記事のデモと色が揃っているか
- [ ] **画像内に煽り文句が入っていないか**（voice.md の ng は画像にも適用する）
