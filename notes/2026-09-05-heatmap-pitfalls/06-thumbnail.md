# 見出し画像のプロンプト

生成先: Gemini（画像生成）
比率: 16:9

## 判断

- 被写体: 縦に潰れて線のようになった格子と、行の高さが揃って読める格子。同じ表が2つ並び、潰れた側だけが灰色に沈んでいる（具体名詞。抽象概念を絵にしない）
- 色: **notes/2026-09-05-heatmap-pitfalls/demo/after.html から取得**（#1971c2 / #e8590c / #ced4da / #ffffff）。デモの「不可」に使うオレンジ #e8590c を、面で1色だけ使う。空きの青 #1971c2 は格子の側に置く
- 美学: 強コントラストのプロダクト写真（黒背景＋強い一灯） — 画面の崩れと直した形を並べて見せる記事であるため
- キーワード: 「5箇所直す」（5文字）

## プロンプト

```
あなたは note の見出し画像を専門とするアートディレクターです。
以下の条件で16:9の画像を1枚作ってください。

## テキスト（これが主役・最優先）

「5箇所直す」を画像内に配置してください。

・**画面の6割以上を文字が占める大きさ**にする
・極太のゴシック体（Black / Heavy 相当）。細い書体を使わない
・文字を **12度 傾ける**。水平に置かない
・文字の背後に強い光源を置き、縁が光って見えるようにする
・文字色は #ffffff。背景とのコントラストを最大にする
・被写体に重なっても構わない。**文字を避けて配置しない**
・縮小表示でも読めることを最優先する

## 被写体（文字の背景として置く）

縦に潰れて線のようになった格子と、行の高さが揃って読める格子。同じ表が2つ並び、潰れた側だけが灰色に沈んでいる

・文字の背後に置く。主役は文字である
・縁を光らせる（エッジライト）
・**左右を対比の構図にする。** 左（潰れた格子）と右（整った格子）を画面の左右に置き、境界を1本の強い光の線で割る

## 色（3色まで。全部を強くする）

・背景: #12161c。明度を極端に振る（ほぼ黒）
・文字: #ffffff
・アクセント: #e8590c。**1色だけ、面で使う**（線で使わない）
・中間色・くすみ色・パステルを使わない。縮小すると灰色になる

## 質感とライティング

・強コントラストのプロダクト写真（黒背景＋強い一灯）
・**強い一灯**。真横からのリムライト1つだけ
・影は硬く、濃く。柔らかい影は縮小すると消える
・高精細、ノイズなし、4K品質

## 避けるもの

・全面に敷くグラデーション
・複数の光源で影の方向がばらつくこと
・要素を3つ以上並べること
・爆発・炎・稲妻・札束・王冠
・画像内に煽り文句を書くこと
・円グラフ、棒グラフ、折れ線グラフ、既製のダッシュボードUIキット風の絵、メーター表示
```

## 生成後の確認

- [ ] **サムネの大きさまで縮小しても、キーワードが読めるか**（最重要）
- [ ] 文字が画面の6割以上を占めているか
- [ ] 文字が傾いているか（水平に整列していないか）
- [ ] 中間色に逃げていないか。3色が全部強いか
- [ ] 記事のデモと色が揃っているか
- [ ] **画像内に煽り文句が入っていないか**（voice.md の ng は画像にも適用する）
