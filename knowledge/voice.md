# voice — 文体定義

このアカウントの文体を定義する。**`scripts/lint.py` がこのファイルを機械的にパースする。**

パース対象は ```rules / ```ng / ```normalize の3ブロックだけである。
それ以外の記述は人間（と執筆エージェント）向けの説明であり、lint.py は読まない。

**note の仕様（テーブル非対応など）はここに書かない。** それはアカウントの文体ではなく
プラットフォームの制約なので、`lint.py` 側にハードコードする。

---

## 基本方針

- **一文を短く。** 読者はスマホで読む。長い一文は画面上で塊に見える
- **改行を多めに。** note は行間が広いので、3〜4行ごとに空行を入れる
- **結論を先に。** 「〜について説明します」ではなく、結論から書いて理由を後ろに置く
- **具体的な数字と固有名詞。** 誇張した形容詞より情報量が多い
- **一人称は「私」。** 「筆者」「当方」は硬すぎる
- **ですます調で統一。** 記事内での混在を lint が検出する

---

## 数値ルール

lint.py が読む。値を変えると判定が変わる。

```rules
maxSentenceLength: 60
hardSentenceLength: 100
maxKanjiRatio: 0.40
maxParagraphLines: 5
minHeadingInterval: 300
```

| キー | 意味 | 超えたら |
|---|---|---|
| `maxSentenceLength` | 一文の文字数 | 警告 |
| `hardSentenceLength` | 一文の文字数 | **エラー**（記事を通さない） |
| `maxKanjiRatio` | 本文中の漢字の比率 | 警告（読みにくい） |
| `maxParagraphLines` | 一段落の行数 | 警告（改行を入れる） |
| `minHeadingInterval` | 見出しの間隔（文字数） | 下回ったら警告（見出しが多すぎる） |

## 禁止表現

lint.py が読む。1行1表現。`#` 以降はコメント。**部分一致で検出する。**

ここに書かれたものは `ethics-line`（E5 断定表現）を待たずに機械が先に潰す。
LLM に判定させるより速く、確実で、トークンを消費しない。

```ng
必ず稼げる          # 収益の断定。景表法
確実に稼げる        # 同上
誰でも簡単に        # 効果の断定
誰でも稼げる        # 同上
絶対に儲かる        # 同上
100%                # 断定。数値としての100%も含めて避ける
リスクゼロ          # 断定
不労所得            # 誤認を招く
放置で              # 誤認を招く
知らないと損        # 煽り
今すぐ行動しないと  # 過度な焦らせ
情報弱者            # 読者を見下す
養分                # 同上
いかがでしたか      # 中身のない定型句
いかがでしょうか    # 同上
参考になれば幸いです # 同上
最後までお読みいただき # 同上
ではないでしょうか  # 曖昧な断定回避。言い切るか書かない
かもしれません      # 同上。多用しない
と思います          # 同上。事実と意見を混ぜない
非常に              # 空虚な強調
とても              # 同上
すごく              # 同上
めちゃくちゃ        # 同上
まさに              # 空虚な強調
まさしく            # 同上
革命的              # 誇張
神ツール            # 誇張
爆速                # 誇張
```

**「と思います」「かもしれません」を禁止に入れている理由:** 事実と意見が混ざると読者が判断できなくなる。意見なら「私は〜と考える」と明示し、事実なら言い切る。曖昧に濁さない。

## 表記統一

lint.py が読む。`誤 -> 正` の形式。

漢字を開く（ひらがなにする）ルールが中心である。形式名詞と補助動詞は開くと読みやすい。

```normalize
出来る -> できる
出来ます -> できます
出来ない -> できない
下さい -> ください
頂く -> いただく
致します -> いたします
有り難う -> ありがとう
宜しく -> よろしく
沢山 -> たくさん
全て -> すべて
殆ど -> ほとんど
既に -> すでに
但し -> ただし
又は -> または
若しくは -> もしくは
尚 -> なお
故に -> したがって
何故 -> なぜ
勿論 -> もちろん
是非 -> ぜひ
様々 -> さまざま
色々 -> いろいろ
毎に -> ごとに
其の -> その
此の -> この
中々 -> なかなか
丁度 -> ちょうど
殊に -> 特に
- 事が -> ことが
- 事を -> ことを
- 事は -> ことは
- 時に -> ときに
- 為に -> ために
- 物を -> ものを
```

> 形式名詞（事・時・為・物）は行頭に `- ` を付けたエントリだけを対象にしている。
> 「事件」「時間」のような通常の熟語まで置換しないため、前後の助詞込みで指定する。

## 使ってよい記法

note で崩れないもの。`lint.py` が別途チェックする。

| 記法 | 使う |
|---|---|
| 見出し（H2 / H3） | ○ |
| 太字 | ○（1記事に5箇所まで。多いと効かなくなる） |
| 箇条書き（2階層まで） | ○ |
| 引用 | ○ |
| 水平線 `---` | ○（note では区切り線になる） |
| コードブロック | ○（言語指定は貼付後に手動で設定する） |
| **テーブル** | **✕ note が非対応。箇条書きにする** |
| 脚注 | ✕ 本文に展開する |
| 3階層以上のリスト | ✕ 崩れる |

---

## 更新の作法

このファイルを変えると全記事の判定が変わる。**変更したら理由を `learnings.md` に記録する。**

特に `ng` ブロックへの追加は慎重に行う。部分一致なので、短い語を入れると誤検出が増える
（例:「絶対」だけを入れると「絶対値」も引っかかる）。
