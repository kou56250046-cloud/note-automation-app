# AIが出したダッシュボードを、色数・目盛り・並びの3箇所で読める形にする

themes.md の id: 2026-W34-01
選定理由: account.md のペルソナ「作れたが画面がテンプレ丸出しで見せられない人」に直撃する。AI に管理画面を作らせるとグラフだけは必ず付いてくるが、系列ごとに違う色が割り当てられ、目盛りが自動で0始まりでなくなる。手元で before/after を作れる。market/2026-08-09.md の「UIデザイン」は需要86.5 / 供給11.9件/日で比7.246、計測14タグ中2位。artifact5（before/afterのデモページ、変更したCSS、AIへの修正指示の全文をすべて出せる）。
今日これを選んだ理由: themes.md で day: mon 指定のテーマであり、曜日の割り当てどおり本日消化する。

## 切り口
W33-01（管理画面の余白・階層・色数）とはグラフを扱う点で分ける。あちらはフォームとテーブルが対象で、こちらは図の描画そのものである。「デザインの原則」を教えず、直す箇所を3つに数え上げる形にする。色数（系列ごとの色を捨てて1色＋強調1色にする）、目盛り（棒グラフの原点を0に戻す）、並び（最重要の数値を左上に置く）の3点に限定する。
