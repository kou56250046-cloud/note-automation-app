# account-design

**ここで決めたカテゴリが、以降すべての記事の範囲になる。**

`weekly-research` は範囲外のテーマを在庫に入れない。したがってこのスキルの出力は、
これから書く数百本の記事の境界線を引く作業である。

---

## 人間に聞かない

**ヒアリングしない。** `account-research` の調査結果と `profile.md` から機械的に決める。

`/note-setup` のような一問一答は v3.0 で廃止した。人間に聞くと、
「なんとなく好きな分野」が選ばれて市場性の判断が飛ぶからである。

判断に迷ったら**調査データに戻る**。ユーザーに戻さない。

---

## 入力

| ファイル | 必須 | 何に使うか |
|---|:---:|---|
| `research/accounts/{genre}.md` | ○ | 参入可否の判定、空白地帯、有料noteの型 |
| `knowledge/profile.md` | ○ | 「書けないこと」。実績が要る領域を避ける |

`research/accounts/` が空なら**停止して `account-research` の実行を促す。** 推測で決めない。

---

## 決めること

### 1. 主カテゴリ（1つだけ）

**1つだけである。2つにしない。**

note のアルゴリズムはアカウント単位で「この人は何の人か」を学習する。
主カテゴリが2つあると、どちらの読者にも中途半端に見え、推薦面に載らなくなる。

選定条件（すべて満たすこと）:

| 条件 | 確認先 |
|---|---|
| `account-research` の参入可否が ○ | `research/accounts/{genre}.md` の結論 |
| 道具型の有料noteが成立している | 同上 |
| `profile.md` の「書けないこと」に抵触しない | 実績が前提の領域を選ばない |
| 空白地帯が3つ以上ある | 書くことが尽きない |

### 2. サブカテゴリ（2〜3つ）

主カテゴリの**内側**を分割する。別のジャンルを足すのではない。

```
✕ 主: AI技術 / サブ: 副業, 料理, 読書
   → 主カテゴリの外に出ている。アカウントが何の人か分からなくなる

○ 主: Claude Code での開発自動化
   サブ: スキル設計 / エージェント設計 / 運用とコスト管理
   → すべて主カテゴリの内側。読者は同じ人として認識する
```

**2〜3つに絞る理由:** 4つ以上あると週7本の配分が散り、同じサブカテゴリが週1本以下になる。
読者が「次も同じ話が読める」と判断できなくなる。

### 3. ペルソナ（購買心理3層）

**1人に絞る。** 「初心者から上級者まで」は誰にも刺さらない。

| 層 | 書くこと |
|---|---|
| **何を信じているか** | 現在の前提。何が正しいと思っているか |
| **何を欲しがっているか** | 表面的な欲求と、その奥にある本当の欲求 |
| **何を感じているか** | 不安・焦り・諦め。まだ言語化されていない感情 |

**行動で書く。状態で書かない。**

```
✕ 「効率化に興味がある人」          → 状態。誰にでも当てはまる
○ 「同じ設定を3回書き直して、いい加減これを自動化したいと思った人」 → 行動
```

### 4. 投稿方針

| 項目 | 決めること |
|---|---|
| 文字数 | 無料記事: 1500〜2500字 / 有料note: 無料部分2000字＋有料部分5000〜8000字 |
| 曜日配分 | 月火水金土 = free / 木日 = paid（変更する場合は理由を書く） |
| サブカテゴリの配分 | 週7本をどう振るか |
| 想定価格帯 | `account-research` の調査から。`pricing-strategy` の初期値になる |

### 5. 書かないこと

**範囲外を明示的に列挙する。** これが `weekly-research` の除外判定の基準になる。

## 判断基準 — 何をもって「決まった」とするか

以下をすべて満たしたときだけ確定とする。

| 条件 | 満たさないとどうなるか |
|---|---|
| 主カテゴリが1つに絞れている | アカウントが何の人か分からなくなる |
| サブカテゴリがすべて主カテゴリの内側にある | 読者が別人の記事だと感じる |
| ペルソナが行動で書かれている | 誰にも刺さらない記事になる |
| 「書かないこと」が3つ以上列挙されている | 除外判定ができず、範囲が広がり続ける |
| 各判断に `research/accounts/` の根拠がある | 好みで決めたことになる |

**満たさない項目があれば `account-research` に戻る。** 埋めるために推測しない。

## やらないこと

- **ユーザーにヒアリングしない。**
- **調査していないジャンルを選ばない。**
- **主カテゴリを2つにしない。**
- **「幅広い読者に向けて」と書かない。** ペルソナは1人に絞る
